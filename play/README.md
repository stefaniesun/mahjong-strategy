# 人机对局 + 打牌辅助器

你坐自己的位置,另外三家由 AI 打;右侧是辅助器,从换三张开始实时显示。

```bash
python -m play.server                                   # 对手:S4 v5(默认)
python -m play.server --ai rule                         # 对手:S3 规则 AI(启动快)
python -m play.server --ai s5 --checkpoint 路径/s5-step-900.pt   # 对手:S5 存档
```

启动后会自动打开浏览器(http://127.0.0.1:8770)。

## 操作

- 换三张:点三张同花色的牌,或点辅助栏里的方案一键选中,再点"换出"
- 定缺:点一门花色
- 出牌:点一下选中、再点一下打出(双击直接打出);能碰、杠、胡时桌面右下角出现按钮
- 你胡了以后可以点"快进到结束";顶栏可以调 AI 出牌速度
- 一局结束后摊牌结算,点"下一局"继续,累计分一直记着

## 记录

每次启动在 `outputs/play/<时间>/` 下生成:

- `handNNN_seedXXX.json`:每局的种子、庄家和每一步动作,可用 `play.session.replay_hand()` 原样复现
- `marks.jsonl`:点"🚩 标记这一刻"存下的局面,含你的备注、当时的牌面和辅助器输出
